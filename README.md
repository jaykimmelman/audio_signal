# audio_signal

Web-based surveillance dashboard prototype that flags red-flag keywords in
teacher lesson transcripts and presents them with an "Enemy of the State"
cinematic feel — click an incident, the satellite map flies to the school,
and the dashboard swaps to the teacher's profile, the lesson transcript with
the trigger word highlighted, and an audio player that jumps to the moment
the keyword was spoken.

## Layout

```
audio_signal/
  preprocess/        Python pre-processor + mock-data generator
  frontend/          React + Vite + TS + Tailwind + Mapbox GL JS
  data/              keyword list + (later) real lesson manifest
  .github/workflows/ GitHub Pages deploy
```

## Quick start

```sh
# 1. Generate mock data (only needed once, or after editing the generator)
cd preprocess
python3 generate_mock_data.py

# 2. Run the frontend
cd ../frontend
npm install
cp .env.example .env       # add your Mapbox token
npm run dev
```

Open http://localhost:5173.

## Mapbox token

The cinematic satellite zoom uses Mapbox GL JS. Get a free public token at
https://account.mapbox.com/access-tokens/ and put it in `frontend/.env`:

```
VITE_MAPBOX_TOKEN=pk.xxxxxxxxxxxxxxxxxxxx
```

Without a token the map area shows a placeholder; the rest of the dashboard
still works.

## Mock vs real data

Right now everything is mock data generated by `preprocess/generate_mock_data.py`:
50 teachers, 20 schools across Kwara state, ~80 signals, transcripts with
segment-level timestamps, audio URLs pointing at a public sample MP3 so the
"jump-to-timestamp" playback actually works.

When real S3 data arrives, replace the generator with the real preprocessor
that reads `data/lessons_manifest.csv` + `data/keywords.txt` and scans the
real transcript JSONs.

## Deploying

Push to GitHub. The included GitHub Action builds the frontend and publishes
it to GitHub Pages (set `VITE_MAPBOX_TOKEN` as a repository secret).
